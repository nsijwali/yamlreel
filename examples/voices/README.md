# Sample voices

Two designed voices (no real person is cloned), 9 seconds each, as a quick way to hear what VoiceStudio can do without recording yourself:

| File | Description given to VoiceStudio |
| --- | --- |
| `female-american.wav` | female, young adult, moderate pitch, american accent |
| `male-american.wav` | male, middle-aged, moderate pitch, american accent |

Both say the same two lines: "A million users ask your database the same question. It answers every time, until it can't. Layer one, the browser. Cache-Control serves files locally."

**Licence.** They were generated with [OmniVoice](https://huggingface.co/k2-fsa/OmniVoice) through [VoiceStudio](https://github.com/debpalash/VoiceStudio). OmniVoice output is CC-BY-NC: use these files non-commercially and credit OmniVoice. They are not covered by yamlreel's MIT licence.

To use a voice like this in a video, design or clone one in VoiceStudio and put its profile id in `voiceover.voice` (see the main README's "Voiceover in your own voice").
